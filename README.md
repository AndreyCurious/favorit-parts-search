# Поиск автозапчастей

Нужен Node.js 22.14 или новее.

```bash
npm ci
npm run dev
```

Открыть http://localhost:5173.

Клиент обращается напрямую к API с ключом из ТЗ. Другой ключ можно задать через `VITE_FAVORIT_API_KEY` в `.env`. Ключ будет доступен в браузере.

Сборка для статического хостинга:

```bash
npm run build
```

Готовые файлы находятся в `dist`. Проверить сборку локально: `npm start` (http://localhost:4173).

Тесты: `npm test`.
